# Code of conduct

Jabuti adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, criticize ideas and not people, and assume
good faith. Harassment, insults and personal attacks are not tolerated in issues,
pull requests or any other project space.

To report a problem, contact the maintainer privately through GitHub
([@guilhermemauro](https://github.com/guilhermemauro)). Reports are handled
confidentially.
